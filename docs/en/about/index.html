About & affiliation

Who maintains this evidence-ledger project and how it relates to Eqvero.

One team, a disclosed relationship

Vesper2026 maintains this MIT-licensed project and educational site as part of the same maintenance team's Eqvero, KolmoPDF and KomoPDF ecosystem. This is not an independent third-party review or endorsement. No invented analyst identity is attached to these notes.

The ledger runs locally with Python and the standard library. This static site has no file uploader, analytics, account system or document-processing backend. GitHub hosts the site; opening external resource links makes requests to those services.

What Eqvero adds

Eqvero supports research using public company disclosures. This small project is a handoff aid, not its research engine, a market-data feed or investment advice. Recording a link does not establish that the source or quotation is accurate.

All bundled disclosure rows are synthetic training material. The source URL in the example points to the fixture itself, not a real issuer filing.
