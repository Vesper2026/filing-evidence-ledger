02 / Method & limitations

A complete evidence row is not a verified source

Separate required fields, number context and human review status before handing a research note to someone else.

By Vesper2026 maintainersPublished 2026-11-03Updated 2026-11-04

There are three different questions in an evidence handoff: is the record complete, did someone inspect the original, and is the interpretation justified? This program answers only the first through deterministic field checks. It stores a user's answer to the second and cannot answer the third.

What the checks actually mean

The required fields are id, question, title, source_url, location and quote. A nonempty value must also have a unit and period. Currency and disclosure date are preserved when provided, but their meaning is not inferred. A percentage, for example, need not have a currency.

{"id":"E02","value":"9.0","unit":"million","period":""}
→ missing:period

This abbreviated row also lacks several required fields. A checklist can therefore contain multiple items for the same row. Duplicate IDs are reported on every affected row, rather than silently replacing an earlier excerpt.

Preserve the source's scale

Use strings for reported values: "0", "12.00" or "(3.2)". The tool retains that representation without doing arithmetic. A numeric JSON value triggers a precision reminder because a parser may already have removed trailing zeros. Do not silently replace an unknown value with zero.

Use status without overstating it

unreviewed is the default; reviewed is a user-entered status. Neither state makes a network request. A valid-looking HTTP URL proves neither availability nor authority, and a quote field can contain incorrect words. Keep a reviewer’s reasoning in the input context or a separate note rather than treating a clean checklist as approval.

Before sharing, check the original disclosure date, page convention and numerical scope yourself. The utility does not fetch documents, reconcile financial statements or assess investments. Run the supplied test suite to reproduce the field rules, not to validate your research claims.

For the broader public-disclosure research step, Eqvero is the related workspace. Keep its source investigation separate from this ledger's field-completeness checks: neither a stored link nor a complete row certifies a claim.
