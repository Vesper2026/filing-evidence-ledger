01 / 可重現教學

建立可覆核的披露證據帳本，保留原文與數字口徑

用三筆合成資料執行本機 CLI，查看兩筆需要人工補充的證據。

研究表格常留下數字，卻遺失定義這個數字的句子。這次練習從引文與位置開始，而不是先填估值模型。範例中的三筆披露內容全部是合成資料，不屬於真實公司公告。

1. 執行隨附範例

準備 Python 3.10 或更新版本，下載或 clone 儲存庫後，在儲存庫根目錄執行。工具沒有執行期第三方依賴。

python filing_evidence.py examples/sample.json --output examples/output
python -m unittest discover -p "test_*.py"

可先查看輸入 JSON。E01 的原句是「Revenue was USD 12 million for FY2025.」，數值以字串 12.00 保存；USD、million、FY2025 分別記錄為幣種、單位與期間。工具不換算數值，也不猜測其他幣種。

2. 把輸出當成交接資料，不是結論

3 evidence rows; 2 need field review. Sources not verified.

ledger.md 按研究問題整理證據；ledger.json 保留原始資料並附上欄位檢查。E02 有數值及單位，卻沒有期間，因此出現 missing:period；E03 有位置但缺少原文，產生 missing:quote。E01 沒有欄位缺漏，也不代表其內容真實。

3. 完成人工覆核

換成自己的資料後，開啟真實公告，確認措辭、頁碼與上下文，再補齊缺漏。範例的來源網址只指向練習資料，不應當成公司公告。reviewed 只記錄你完成的工作，與工具的欄位檢查互不替代。

需要跨公告追查問題時，可使用相關的 Eqvero 公開披露研究工作流。這個 MIT 工具仍然只是本機記錄整理器，不核驗事實，也不提供投資建議。
