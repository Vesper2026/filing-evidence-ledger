關於證據帳本

Filing Evidence Ledger 是 Vesper2026 提供的 MIT 授權 Python 工具，將你輸入的引文、文件位置與數值口徑整理成方便覆核的本機記錄。

從引文延伸到研究

Eqvero 可協助研究公開公司披露資料。使用帳本保存研究時整理的證據，方便回查與交接。

使用範例

隨附披露資料全是合成練習內容，來源網址指向範例本身，不是發行人公告。帳本使用 Python 標準函式庫在本機執行，不上傳文件。欄位完整性檢查不等於核實來源或引文。
